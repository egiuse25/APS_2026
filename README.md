# Prácticas de Análisis y Procesamiento Digital de Señales

Este repositorio contiene una colección de trabajos prácticos y simulaciones desarrolladas para el estudio del procesamiento digital de señales. Los algoritmos y análisis están implementados principalmente en Python utilizando Jupyter Notebooks.

## Temas Abordados
* *Conceptos Básicos:* Síntesis y operaciones fundamentales de señales.
* *Muestreo y Cuantización:* Modelado de conversores Analógico-Digital (ADC).
* *Análisis Espectral:* Aplicación de la Transformada Rápida de Fourier (FFT), fenómenos de desparramo (leakage), interpolación y técnicas de ventaneo.
* *Señales Reales:* Estimación espectral y análisis de ancho de banda.
* *Filtros Digitales:* Aplicación de la Transformada Z, análisis de respuesta en frecuencia y diseño de filtros.
* *Aplicación Biomédica:* Filtrado digital lineal aplicado a señales reales de Electrocardiograma (ECG).

## Herramientas Tecnológicas
* Python
* Jupyter Notebook
* Librerías: NumPy, SciPy, Matplotlib
